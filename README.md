# Minecraft Username Sniper

## This is a simple Python Username Sniper for Minecraft

**TO RUN**:

1. Download File (or repo it )
2. do `pip install requests`
3. Set your webhook
4. Run (`python 4Letter.py` `python 3Letter.py`)
